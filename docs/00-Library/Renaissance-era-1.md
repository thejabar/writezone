🧭 The Founder Compass

I believe every board meeting should begin with the same five questions.

1. Does this strengthen trust?
2. Does this deepen understanding?
3. Does this preserve knowledge?
4. Does this simplify the platform?
5. Will we still be proud of this decision in ten years?

If we honestly answer those questions every time, many difficult decisions become much clearer.
