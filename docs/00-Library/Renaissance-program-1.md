Signal Zero

Before we implement any signal…

We need one object.

Signal

Today we have:

$writ->signals['relationship'] = 40;

That won’t scale.

Instead:

$relationship = new Signal(
    name: 'relationship',
    value: 40,
    reason: 'Author is followed'
);

Now every signal explains itself.

⸻

Every Signal should answer four questions

What is your name?
What is your value?
Why were you produced?
Which engine produced you?
