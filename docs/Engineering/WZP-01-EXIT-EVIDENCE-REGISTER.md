This register maps each existing WZP-01 exit criterion to present documentary/source evidence. WZP-01.8 records closure with conditions and adopts E-08 only at the WZP-01 documentary boundary. The status column evaluates only whether the WZP-01 criterion is evidenced, not whether dependent code, tests, environments, operations, or releases are complete. `SATISFIED` never substitutes for implementation, independent verification, WZP-02 exit, or beta readiness.

## Evidence and status vocabulary

- **Evidence strength:** Documentary; Source-inspected; Independently verified; Absent. No independent verification was performed in this task.
- **Status:** SATISFIED; PARTIALLY SATISFIED; OPEN; BLOCKED; NOT APPLICABLE.
- Approved policy may satisfy a decision-record criterion while its implementation remains outstanding.
- A blocker satisfies a WZP-01 record criterion only where the Project Owner explicitly allows the blocker to be recorded. It never authorizes dependent work.
- WZP-02 exit evidence is required before beta, not before WZP-01 closure. D11-D13 are not mandatory WZP-01 closure requirements while excluded from B.
